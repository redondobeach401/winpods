# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, acepta las críticas constructivas y céntrate en
lo mejor para la comunidad. No se toleran el acoso ni los ataques personales.

Para informar de un comportamiento inaceptable, contacta con los mantenedores mediante un
aviso privado en GitHub.
